# Proof of Concept Source Files

This folder contains the nonproduction browser prototype and its supporting tests, evaluation scripts, and sanitized deployment configuration.

The current prototype is stored in `unit4-prototype` because the same implementation has been developed incrementally since Unit 4. Unit 5 added the separated policy functions and automated tests. Unit 6 added the benchmark, evaluation records, Dockerfile, Nginx configuration, health check, and deployment guidance. Unit 7 added a repeatable headless Chrome suite for system, integration, and requirement-based acceptance testing, executed container validation, and representative-user follow-up improvements. Unit 8 packages the validated prototype as the final public portfolio release without changing the established policy behavior.

See the [prototype run guide](unit4-prototype/README.md) for the local Mac test, benchmark, browser, and planned container procedures.

No credentials, tenant secrets, private keys, production exports, personal information, or organization-specific identifiers belong in this folder.
