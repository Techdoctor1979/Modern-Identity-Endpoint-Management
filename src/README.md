# Proof of Concept Source Files

This folder contains the nonproduction browser prototype and its supporting tests, evaluation scripts, and sanitized deployment configuration.

The current prototype is stored in `unit4-prototype` because the same implementation has been developed incrementally since Unit 4. Unit 5 added the separated policy functions and automated tests. Unit 6 adds the benchmark, evaluation records, Dockerfile, Nginx configuration, health check, and deployment guidance.

No credentials, tenant secrets, private keys, production exports, personal information, or organization-specific identifiers belong in this folder.
