# Sanitized Screenshots

Place only screenshots that have been reviewed for assignment use in this folder. Use descriptive names such as `EV-FR05-001-compliance-result.png` and add the matching record to `../evidence-index.md`.

Do not add full-screen captures when a cropped view can show the required result. Remove or obscure personal information, account details, tenant identifiers, device serial numbers, IP addresses, tokens, and unrelated applications.
